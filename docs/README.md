# Документация GP Horizon

GP Horizon управляет обходом блокировок на роутерах Keenetic с Entware: обход DPI
(nfqws2), туннель Cloudflare WARP и собственный сервер VLESS (xray) — по спискам доменов,
из одной панели. Обзор проекта, установка и скриншоты — в [README](../README.md).

| Документ | Для чего |
|---|---|
| [Установка по этапам](BETA.md) | Пошаговая установка на роутер и Pi с проверкой и откатом на каждом этапе: подготовка роутера, лайт, фул, плагин GP, списки, применение, VLESS, защищённый DNS, обновление и удаление. |
| [Справочник команд](commands.md) | Команды `nuxk` и `nuxk-pi`, их параметры и переменные окружения; init-скрипты движков; флаги агента и режимы контроллера; команды диагностики и разработки. |
| [Конфигурация](configuration.md) | Все ключи `nuxk.conf` со значениями по умолчанию; переменные окружения контроллера; файлы, каталоги и сетевые порты. |

## Термины

| Термин | Значение |
|---|---|
| **Лайт** | Установка только на роутер: агент и лёгкая панель на `:4141`. |
| **Фул** | Лайт плюс контроллер на Raspberry Pi: полная панель на `:4200`, история графиков, подбор стратегий, серверы VLESS. |
| **Агент** (`nuxk-core`) | Программа на роутере: движки, списки, маршрутизация, проба, DNS, API. |
| **Контроллер** (`nuxk-controller`) | Программа на Pi: полная панель, прокси к агенту, хост плагинов. |
| **Движок** | nfqws2 (DPI), usque (WARP) или xray (VLESS). |
| **Списки** | Домены по трём путям: DPI, WARP, VLESS. |
| **Плоскость маршрутизации** | Часть агента, которая превращает списки WARP и VLESS в объекты маршрутизации Keenetic `nuxk-*`. |
| **Режим плана** | `PLANE_APPLY="0"`: агент показывает, что изменил бы на роутере, и ничего не меняет. |
| **Проба** | Регулярная проверка движка: открываются ли сайты, на каком этапе обрывается соединение. |
| **Прогон** | Подбор стратегий nfqws2 плагином GP для выбранных доменов. |
