# nuxk 0.1.0-beta.1 — установка

Бета состоит из двух частей:

| Где | Что работает | Как ставится |
|---|---|---|
| **Raspberry Pi 5** (192.168.2.10) | стенд с настоящими usque (WARP) и nfqws2 + **инсталлятор** для роутера | `deploy/pi/bootstrap.sh` |
| **Роутер Keenetic** | nuxk-core, веб-панель, nfqws2 (штатный пакет `nfqws2-keenetic`) | форма инсталлятора на Pi |

WARP и VLESS на роутер в beta.1 не ставятся: они работают на стенде Pi.

---

## 1. Роутер: подготовка (один раз, руками)

Инсталлятор ставит всё, что ставится через `opkg`. Компоненты KeeneticOS и сам
Entware он поставить не может — это делается в веб-интерфейсе роутера.

1. **Обновите KeeneticOS** до актуальной 4.x.
2. **Компоненты.** «Управление → Параметры системы → Изменить набор компонентов»,
   отметьте и установите (роутер перезагрузится):
   - «Поддержка открытых пакетов OPKG»;
   - «Модули ядра подсистемы Netfilter» — без них nfqws2 не запустится;
   - «Протокол IPv6» — чтобы nfqws2 обрабатывал и IPv6-трафик.
3. **Entware.** Если ещё не стоит — по инструкции Keenetic «Установка системы
   пакетов репозитория Entware на USB-накопитель» (флешка в ext4; на моделях с
   большой памятью можно во внутреннюю). После установки у Entware свой SSH:
   **порт 222, логин `root`, пароль `keenetic`**.
4. **Смените пароль Entware** (стандартный знают все):
   ```sh
   ssh root@192.168.2.1 -p 222      # пароль keenetic
   passwd
   ```
5. **Время.** «Управление → Параметры системы → Дата и время» — включите
   синхронизацию (NTP). С неверными часами не работает HTTPS до репозиториев;
   инсталлятор предупредит, если часы расходятся.

Проверка: `ssh root@<роутер> -p 222`, затем `opkg update` без ошибок.

> Порт **22** — это CLI самого Keenetic, туда инсталлятор не подключается.
> Нужен SSH Entware на **222**.

## 2. Raspberry Pi: развернуть стенд и инсталлятор

На Pi нужны 64-битная Raspberry Pi OS, Docker с `docker compose` 2.20+ и git.

Репозиторий приватный, поэтому Pi нужен доступ к GitHub: SSH-ключ Pi в
«Settings → SSH and GPG keys» или токен (PAT) с правом чтения репозитория.

```sh
git clone git@github.com:AtomAlex12/nuxk-horizon.git ~/nuxk-horizon   # или https:// с токеном
cd ~/nuxk-horizon
sh deploy/pi/bootstrap.sh
```

Если на Pi уже был старый стенд `deploy/proto`, скрипт остановит его (тома
сохраняются) и перенесёт регистрацию WARP — второй раз регистрироваться не нужно.

Скрипт можно запускать повторно. Он:
1. проверяет Pi (arm64, Docker, compose, `/dev/net/tun`);
2. загружает модули ядра для nfqws2 и прописывает их в автозагрузку;
3. обновляет клон до `main` — другая ветка или тег через
   `NUXK_REF=v0.1.0-beta.1 sh deploy/pi/bootstrap.sh`;
4. создаёт `deploy/pi/.env` (этап A — только WARP);
5. собирает образы (первый раз 5–10 минут);
6. один раз регистрирует устройство WARP — **прочитайте и подтвердите условия
   Cloudflare** в терминале;
7. запускает стек и печатает адреса и код доступа:

```
  Дашборд стенда:      http://192.168.2.10:4242/
  Установка на роутер: http://192.168.2.10:4300/
  Код доступа:         XXXX-XXXX
```

Этапы стенда — в `deploy/pi/.env` (после правки: `docker compose -f deploy/pi/docker-compose.yml up -d`):
`NUXK_ENABLE_DNS_GLUE=1` — этап B, `NUXK_ENABLE_NFQWS2=1` — этап C.

## 3. Роутер: установка через форму

1. Откройте **http://192.168.2.10:4300**.
2. Нажмите «Квартира · 192.168.2.1» (или введите адрес), порт **222**, `root`,
   пароль Entware, код доступа из вывода скрипта.
3. **«Проверить роутер»** — только чтение. Форма покажет:
   - что уже есть (Entware, архитектура, место, модули ядра, пакеты);
   - чего не хватает — с галочками;
   - что требует ваших рук (жёлтое) и что блокирует установку (красное).
4. Сверьте ключ SSH роутера (строка над таблицей) — дальше установка пойдёт
   только к роутеру с этим ключом.
5. **«Установить выбранное»**. Инсталлятор по порядку:
   - `opkg install` недостающих `curl`, `ca-certificates`, `ipset`;
   - подключает репозиторий `nfqws.github.io/nfqws2-keenetic` и ставит
     `nfqws2-keenetic`;
   - копирует nuxk-core под архитектуру роутера, `S99nuxk-core`, адаптер
     `S51nfqws2-nuxk`, веб-панель;
   - создаёт `/opt/etc/nuxk/nuxk.conf` (права 0600): адрес только в LAN
     (`<IP роутера>:4141`), новый API-токен;
   - запускает nuxk-core и проверяет `/api/v1/healthz`.
6. В конце — адрес панели и **API-токен**. Сохраните токен в менеджер паролей.

Повторный запуск безопасен: ставится только недостающее, существующий
`nuxk.conf` не перезаписывается, при обновлении старый бинарник остаётся как
`/opt/usr/bin/nuxk-core.prev`.

**Домашний роутер (192.168.1.1).** Pi стоит в квартире (192.168.2.0/24) и
домашнюю сеть не видит. Запустите инсталлятор в домашней сети — на Docker-хосте
192.168.1.100 (`make installer`, бинарник `nuxk-installer-linux-amd64`) или на
ноутбуке (`nuxk-installer-windows-amd64.exe` из релиза), затем откройте
`http://<этот хост>:4300`.

## 4. После установки

1. Откройте `http://192.168.2.1:4141`, введите токен.
2. Карточка nfqws2 должна быть «работает». Если «остановлен» и в ошибке
   NFQUEUE — не хватает модулей ядра (пункт 1.2): включите компонент,
   перезагрузите роутер, повторите проверку в инсталляторе.
3. nuxk-core стартует сам после перезагрузки роутера (Entware запускает
   `/opt/etc/init.d/S99nuxk-core`).

Полезное на роутере:

```sh
/opt/etc/init.d/S99nuxk-core status        # работает ли
tail -f /opt/var/log/nuxk-core.log         # лог
/opt/usr/bin/nuxk-core -version            # версия
cat /opt/etc/nuxk/nuxk.conf                # конфиг и токен
```

## 5. Откат

```sh
/opt/etc/init.d/S99nuxk-core stop
rm -f /opt/usr/bin/nuxk-core* /opt/etc/init.d/S99nuxk-core
rm -rf /opt/etc/nuxk /opt/share/www/nuxk
# nfqws2 тоже, если ставил инсталлятор:
opkg remove nfqws2-keenetic && rm -f /opt/etc/opkg/nfqws2-keenetic.conf
```

Вернуть прошлую версию nuxk-core: `mv /opt/usr/bin/nuxk-core.prev /opt/usr/bin/nuxk-core`
и `/opt/etc/init.d/S99nuxk-core restart`.

## Что проверено до релиза и что нет

- Проверено: юнит-тесты и сквозной тест инсталлятора через настоящий SSH на
  имитации роутера (поддельные `opkg`, `ndmc`, `lsmod`), форма в браузере,
  прослойка nfqws2 под dash, сборка ядра под mips/mipsel/aarch64/x86_64.
- **Не проверено на железе:** реальный Keenetic и реальный пакет
  `nfqws2-keenetic`, сборка образа инсталлятора на Pi. Это первая проверка беты —
  если что-то упадёт, пришлите вывод формы и `tail -50 /opt/var/log/nuxk-core.log`.
