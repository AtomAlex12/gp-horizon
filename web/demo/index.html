Вход

Демо: любой логин и пароль.

API — POST /api/index.php

Полный контракт — web/openapi.yaml, отдаётся на :91/openapi.yaml.

cmd=status        → сервис, туннель, iface, трафик, маршруты
cmd=probe         → ok, egress_ip, warp, colo, loc, rtt_ms
cmd=log&lines=N   → хвост usque.log
cmd=config_get    → IFACE, IFACE_IP, IFACE_MASK, MTU, SNI, HTTP2_ENABLE
cmd=config_set    → iface? iface_ip? iface_mask? mtu? sni? http2? → restart
cmd=route_get     → presets[], list, domains, prefixes
cmd=route_set     → list? presets? → резолв + маршруты на opkgtun
cmd=start|stop|restart|reregister
cmd=login&user&password   ·   cmd=logout
